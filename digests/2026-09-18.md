## Deep-read Candidates

### 1. PROVIA: Procedure State Tracking for Online Mistake Detection in Egocentric Videos

- Campaign：Video and Streaming Reasoning
- 问题：在线助手如何仅凭过去帧检测程序错误，并在用户纠正后继续追踪，而不是利用首次错误截断带来的时间捷径。
- 去包装后的真实变量：将已发生步骤的 factual state 与正确流程的 accepted-progress posterior 分开；在完整 trials、固定 false-alarm budget 和 timing-only controls 下做 sequential alarm。
- 为什么值得深读：它直接挑战常用 first-mistake protocol，并把“看到了什么”和“正确流程走到哪”拆成两个可独立审计的状态。
- 证据缺口：`abstract-only`；需检查 automaton 诱导、报警延迟、跨 actor 泛化、低绝对 recall 与所有 timing shortcut controls。代码仓库可访问不等于结果已复现。
- Paper：https://arxiv.org/abs/2609.20638
- Code：https://github.com/Kratos-Wen/PROVIA

### 2. Workspace Models: Lightweight Robotic Memory via Saliency-Driven Supervision

- Campaign：Video and Streaming Reasoning；Agentic Visual Reasoning
- 问题：长时机器人 policy 如何保留任务相关历史，同时避免全历史条件的虚假相关和部署时 VLM 查询成本。
- 去包装后的真实变量：训练时用 VLM 标注当前/历史显著信息，再通过 set-reconstruction loss 蒸馏成单个 workspace token，部署时以 latent memory 替代历史观测。
- 为什么值得深读：它把昂贵 VLM 从在线推理器改为离线“记忆监督器”，可直接测试 teacher saliency、memory capacity 与 deployment latency 的权衡。
- 证据缺口：`abstract-only`；需排除教师使用未来信息、比较 matched memory/compute、核对硬件任务规模和显著性重构是否对应因果任务状态。
- Paper：https://arxiv.org/abs/2609.20820

### 3. Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation

- Campaign：Agentic Visual Reasoning
- 问题：agent 已在轨迹中提到障碍且 prompt 明确禁止碰撞时，为何安全约束仍未进入执行优先级。
- 去包装后的真实变量：bounding-box grounding 后的 waypoint route generation/verification/replanning，以及单独的避障 contact-position selection。
- 为什么值得深读：它把“知道但没做”拆成路径清障、不可行后重规划与接触边界三个可测试 harness 变量。
- 证据缺口：`abstract-only`；需检查 perception-vs-planning 归因、候选路径/验证额外调用、matched-budget baseline、任务规模和 success–safety trade-off。
- Paper：https://arxiv.org/abs/2609.20822

## Watchlist
