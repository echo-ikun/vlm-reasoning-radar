# VLM Reasoning Radar — 2026-08-04

## 今日判断

- 一句话趋势：近期最有价值的信号不是又一个更高分模型，而是多篇工作开始审计“模型是否真的使用视觉证据”，并暴露解码格式、旧 CoT 文本和 outcome-only reward 带来的假增益。
- 最值得关注的 campaign：`multimodal-reasoning-post-training`，其次是 `video-streaming-reasoning`。
- 潜在研究窗口：建立一套 matched-control 的视觉证据使用评测，将答案正确率、视觉更新率、证据定位和推理预算同时控制。
- 证据范围：本轮为首轮 dry run，仅核对 arXiv 官方 API 元数据与摘要，所有记录均标为 `abstract-only`。

## Must Read

### 1. Recompute or Reuse? Diagnosing and Mitigating Textual Shortcuts in VLM Self-Reflection

- Campaign：Agentic Visual Reasoning / Multimodal Reasoning Post-training
- Primary branch：Evaluation
- 问题：图像发生变化后，VLM 是否真的重新看图，还是沿用旧 CoT 中的证据文本？
- 核心方法：matched counterfactual analysis，加上隔离旧 CoT 与新计算的 training-free attention firewall。
- 主要证据：摘要报告覆盖 16 个 VLM；在 5 个 VLM 上，visual update rate 从 35.28% 提升到 53.61%。
- 研究价值：把 self-reflection 的失败具体化为可干预的 textual shortcut，容易形成更广泛的视觉证据复用研究。
- 局限：尚未全文检查反事实数据是否保持难度和答案分布一致。
- [Paper](https://arxiv.org/abs/2608.01930) · [PDF](https://arxiv.org/pdf/2608.01930)

### 2. It's the Decoding Format, Not the Perturbation

- Campaign：Multimodal Reasoning Post-training
- Primary branch：Evaluation
- 问题：视觉扰动一致性选择的收益，是否其实来自解码格式或额外推理预算？
- 核心方法：加入相同短答案、无 CoT、相同预算的 `MatchedCtrl`。
- 主要证据：摘要称在 TextVQA、MATH-Vision、MMMU、ViLP 上，MatchedCtrl 与扰动选择持平或更好。
- 研究价值：提供了一个可直接复用的 VLM test-time scaling 评测原则——比较方法必须匹配格式、采样数和 token 预算。
- 局限：需要全文核对 seed、显著性、prompt 和 perturbation coverage。
- [Paper](https://arxiv.org/abs/2608.01207) · [PDF](https://arxiv.org/pdf/2608.01207)

### 3. CAVE: Competence-Aware Visual Boundary Evidence Alignment for Video Temporal Grounding

- Campaign：Video and Streaming Reasoning / Multimodal Reasoning Post-training
- Primary branch：Learning and Post-training
- 问题：只奖励最终时间区间正确，会不会让模型给出正确 timestamp，却没有使用对应的边界视觉证据？
- 核心方法：boundary evidence tokens、SFT warm-up、视觉边界对齐奖励和 competence-aware gating。
- 主要证据：摘要称在多个 VTG benchmark 上有效，但没有具体数字。
- 研究价值：和前两篇共同指向“答案正确不等于视觉证据正确”，并把问题落到 video RL。
- 局限：attention reward 可能被投机，必须检查因果干预而非只看可视化。
- [Paper](https://arxiv.org/abs/2608.02078) · [PDF](https://arxiv.org/pdf/2608.02078)

## Research Opportunity Signals

### Signal A — Matched-control VLM reasoning audit

两篇独立新工作分别指出：旧 CoT 可成为视觉重计算的文本捷径；不匹配的 decoding format 可制造 test-time scaling 假增益。二者可以统一成一个低成本研究问题：

> 当图像证据变化时，在匹配输出格式、采样预算和 token 预算后，现有 reflection、self-consistency、verifier 与 agent loop 还有多少真实增益？

最小实验可以同时报告：answer update rate、visual evidence localization、stale-rationale reuse、accuracy 和总推理 token。

### Signal B — Evidence alignment before outcome optimization

CAVE 与 SpatialAfford 都认为只优化最终输出不足，需要先让模型的视觉证据与输出目标对齐。机会点不在再加一个 attention loss，而在检验：

- 对齐后的 attention 是否对答案具有因果作用？
- 模型是否可以在不看正确证据的情况下投机 evidence reward？
- competence-aware 退火何时优于固定过程监督？

### Signal C — Reasoning-preserving compression

Messages, Not Tokens 和 Coverage-Driven Keyframe Selection 分别从 token message 与 temporal coverage 出发。一个自然的 video/streaming 延伸是：用“回答所需证据集合是否仍可恢复”作为压缩目标，而不是只比较平均 benchmark accuracy。
