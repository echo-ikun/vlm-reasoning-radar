## Deep-read Candidates

### 1. OmniSeek: Native Tool Integration for Multi-turn Audio-Visual Reasoning

- Campaign：Agentic Visual Reasoning；Video and Streaming Reasoning；Multimodal Reasoning Post-training
- 问题：关键证据跨音频与视频、且只在稀疏时间窗出现时，模型能否主动决定看或听以及检索何处。
- 去包装后的真实变量：modality × temporal-window 工具路由、17 万交错证据轨迹、两阶段 RLVR，以及只奖励真正依赖两种模态成功轨迹的 necessity objective。
- 为什么值得深读：它把 active perception 从单一视觉 crop/zoom 扩展为跨模态时间取证，并给出了可直接审计的路由与奖励接口。
- 证据缺口：`abstract-only`；需拆开数据、SFT、RL 与 necessity reward，核对教师/污染、matched media/token/tool-call 预算、单模态 shortcut、路由准确率和多轮误差累积。
- Paper：https://arxiv.org/abs/2610.02181

### 2. Video-Index: A Curated Meta-Benchmark for Video Understanding

- Campaign：Video and Streaming Reasoning；Multimodal Reasoning Post-training
- 问题：现有视频 benchmark 的分数是否真的需要视觉与时间证据，而非答案选项、问题文本、局部帧、乱序帧或近重复。
- 去包装后的真实变量：五级 shortcut attack pyramid、跨 115 个 benchmark 的审计，以及从 505,518 个 QA 中经确定性选择与 red-team gate 筛出的 840 个验证项。
- 为什么值得深读：若摘要统计成立，许多 video reasoning 结论的测量基础需要重估；它也提供了可复用的 benchmark 进入门槛。
- 证据缺口：`abstract-only`；需核对攻击接近阈值、近重复定义、来源污染与许可、840 项代表性、人工一致性，以及 agent tools 约 20 点收益的 matched-budget 对照。
- Paper / Code / Dataset：https://arxiv.org/abs/2610.00960 · https://github.com/Espere-1119-Song/Video-Index · https://huggingface.co/datasets/Video-Index/Video-Index

### 3. ECoMEM: Explicit Concept Memory for Memory-Dependent Robot Control

- Campaign：Agentic Visual Reasoning；Video and Streaming Reasoning；Multimodal Reasoning Post-training
- 问题：对象离开视野、示范结束或任务进度变化后，VLA 应明确保留和更新哪些事实。
- 去包装后的真实变量：预定义或可扩展的 grounded concept library、evidence-based Writer，以及把概念记录映射为 VLA memory tokens 的 learned Reader。
- 为什么值得深读：它把 memory content 从隐式历史压缩变成可检查、可干预的概念状态，可直接与 D&R、MemBodied 和 PREM 对齐。
- 证据缺口：`abstract-only`；需检查概念定义成本、Writer 的未来/oracle 信息、容量与视觉预算匹配、16 任务逐项结果、真实机器人试验数和概念迁移边界。
- Paper / Project：https://arxiv.org/abs/2610.00801 · https://ecomem.github.io/

## Watchlist

- **VISTA** — 用 lossless visual store、主动检索和输入重组为闭源底模提供长时交互记忆；ARC-AGI-3 结果强，但需拆分三个组件并匹配调用、图像 token、存储和公开任务污染。https://arxiv.org/abs/2610.02200
- **Where-OPD** — 教师在合成场景中获得 query-relevant 对象身份/坐标，学生仅看图像和问题做 on-policy self-distillation；需排除普通合成 SFT 与答案相关 oracle guidance 即可解释 3.23 点迁移。https://arxiv.org/abs/2610.02117
- **FlashBack** — 先判断是否需要历史，再用隔离 Side-KV Recall trajectory 避免污染实时 Native state；需报告 gate 的漏召回/误召回、端到端延迟与 matched FLOPs，且代码尚未验证。https://arxiv.org/abs/2610.01192
- **Video Evidence Indexing** — 从低分辨率全局 preview 分配高分辨率 Evidence Set，并由 answer-aware teacher 自蒸馏；需匹配总视觉计算并检查 teacher 泄漏及离线全览是否被误称为 online。https://arxiv.org/abs/2610.00757
- **Embodied Agent Arena** — 将几何、空间、affordance、规划、操作与原生任务完成分层；价值取决于 32 来源的尺度/重复控制，以及局部能力能否预测终局成功。https://arxiv.org/abs/2610.00854
