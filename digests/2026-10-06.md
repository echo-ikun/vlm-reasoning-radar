## Deep-read Candidates

### 1. CASE: Cost-Aware Stopping for Efficient Long-Video Agents

- Campaign：Video and Streaming Reasoning；Agentic Visual Reasoning
- 问题：逐步取证的长视频 agent 何时已经看够，应立即回答而不是继续消耗模型调用。
- 去包装后的真实变量：在同一原生搜索路径上构造 answer-now 相对 stop-later 的 cost-aware target，再以当前证据测验与 host execution state 预测 STOP/CONTINUE。
- 为什么值得深读：它把 response timing 从 prompt heuristic 变成可度量 policy，可和 OneStreamer 的主动回答、FlashBack 的 recall gate 放到统一 accuracy–cost–coverage 时间轴。
- 证据缺口：`abstract-only`；需审计完整轨迹带来的 hindsight、辅助选择题的额外信息与计算、cost 定义、早停误差、不同 operating point 的完整 Pareto 曲线。
- Paper：https://arxiv.org/abs/2610.05400

### 2. SpatialChain: A Benchmark for Auditing Spatial Reasoning Faithfulness in VLMs

- Campaign：Agentic Visual Reasoning；Multimodal Reasoning Post-training
- 问题：空间问题答对时，如何识别依赖语言捷径或装饰性长链的“非忠实正确”。
- 去包装后的真实变量：scene-graph-grounded reference chain，加上答案准确率之外的 chain overlap、忠实性和完整性评测。
- 为什么值得深读：它能直接检验 CROSS 等显式 spatial schema 是否改善实际证据链，而不仅是末端分数。
- 证据缺口：`abstract-only`；需复核 chain 多解性、LLM judge 的长度/风格偏差、198 条人工验证覆盖、生成链按答案一致性筛选的偏差，以及外部 benchmark specialization。
- Paper / Code：https://arxiv.org/abs/2610.06413 · https://github.com/spatialchain/SpatialChainBenchmark

### 3. MeSD: Multi-Evidence Self-Distillation for VideoLLM

- Campaign：Multimodal Reasoning Post-training；Video and Streaming Reasoning
- 问题：outcome reward 缺少 token 级指导时，怎样利用不同视觉证据教师而不掩盖证据冲突。
- 去包装后的真实变量：answer、temporal、spatial 三个共享参数教师；共同 preference 与 gated residual 融合；按轨迹状态选择 advantage magnitude refinement 或 reverse-KL correction。
- 为什么值得深读：它把 privileged teacher 的信息拆成可消融的证据来源，可检验 self-distillation 的收益来自优化方式还是额外 oracle 信息。
- 证据缺口：`abstract-only`；摘要没有绝对结果、模型/数据或训练成本。需审计 evidence oracle、三分轨迹分类误差、teacher forward 成本、同算力单教师/RLVR 对照与视觉 groundedness。
- Paper：https://arxiv.org/abs/2610.06342

## Watchlist

- **VideoTapestry** — 三层 query-independent memory 经多 agent 回看变成 query-adaptive memory；需先匹配 GPT-5.5 的帧、调用、上下文与成本，避免把更多视频访问误认成层级记忆收益。https://arxiv.org/abs/2610.06672
- **VepAgent** — CoT 数据、状态跟踪/帧检索/区域放大工具与复合 RL reward 联合用于视频事件预测；首要风险是 observation cutoff 后的未来证据泄漏。https://arxiv.org/abs/2610.06293
- **Readout Blindness** — 以 antisymmetric displacement readout 恢复冻结 encoder 中的方向信息，并用 unrelated-image null 去除文本先验；它是 spatial reasoning 的低层控制，不等于已解决多步推理。https://arxiv.org/abs/2610.06324
- **Rethinking Long-Video Efficiency / LoHi** — 联合分配帧密度、像素分辨率和前端解码延迟；需把 CLIP selector、codec 解码、总像素/FLOPs 与视觉 token 一起纳入 Pareto。https://arxiv.org/abs/2610.04318
