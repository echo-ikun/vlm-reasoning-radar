## Deep-read Candidates

### 1. Open-o3-Video-v2: Seek, Ground, and Reason with Verifiable Spatio-Temporal Evidence

- Campaign：Agentic Visual Reasoning；Multimodal Reasoning Post-training；Video and Streaming Reasoning
- 问题：初始稀疏采样不足时，视频模型怎样主动补取时空证据，并将答案关联到可核验的时间点与对象。
- 去包装后的真实变量：额外观察实际带来的新证据、写入轨迹的接口和检索奖励；不是 trace 格式或“agentic video”本身。
- 为什么值得深读：可直接检验主动补帧能否在相同帧/token/rollout/延迟下，提高证据召回而非只是扩大可见证据池。
- 证据缺口：`abstract-only`；需审计候选帧访问、工具次数与总预算、框级证据正确性、同预算 uniform/oracle retrieval、数据泄漏和错误答案时 trace 的忠实性。作者摘要列出代码、模型和数据入口，本轮未验证可用性。
- Paper / Project：https://arxiv.org/abs/2610.17656 · https://msalab-pku.github.io/projects/Open-o3-Video-v2

### 2. DeltaStreamer: Towards Human-Like Agentic Streaming Video Understanding

- Campaign：Video and Streaming Reasoning；Agentic Visual Reasoning
- 问题：在查询前未知需求的 streaming video 中，怎样记录变化，并在查询后恢复压缩阶段遗漏的证据。
- 去包装后的真实变量：预查询 change-aware memory、查询后 replay 的访问范围与 planner；不是泛化的 memory 模块。
- 为什么值得深读：它把“先记什么、后补什么”明确成可做因果/预算对照的 streaming 变量。
- 证据缺口：`abstract-only`；需确认 replay 是否符合严格 online 定义，并对齐预查询内存、总帧/token/调用、查询延迟和短暂事件召回；项目页未验证。
- Paper / Project：https://arxiv.org/abs/2610.19849 · https://bbbbchan.github.io/DeltaStreamer/

### 3. EventLens: Event-Structure Reinforcement Learning for Video Understanding

- Campaign：Multimodal Reasoning Post-training；Video and Streaming Reasoning
- 问题：如何让视频 MLLM 恢复事件边界、事件演化与跨事件关系，而非利用字幕式语言捷径。
- 去包装后的真实变量：由顺序/粒度/进展扰动定义的 event-structure 任务与确定性奖励；不是一般 video RL。
- 为什么值得深读：若这些扰动确实要求视觉时序结构，便提供了比 caption supervision 更可控的 post-training 信号。
- 证据缺口：`abstract-only`；需检查任务捷径、ontology 与标签误差、同 rollout/token 的 caption-RL/SFT 对照、教师泄漏和视频 QA 保持。
- Paper：https://arxiv.org/abs/2610.16172

## Watchlist

- **Neos** — 将 visual evidence interface 与后续 search decision 共适应；先核对视觉依赖过滤、检索池和相同工具预算。https://arxiv.org/abs/2610.17043
- **ActICL** — 将“何时继续获取 context”作为后训练目标；需先验证 benchmark 的视觉必要性与 adaptive retrieval 的调用对齐。https://arxiv.org/abs/2610.19475
- **What Breaks in Multi-Image Schema Application?** — factorial oracle 指向有序实例恢复瓶颈；先判断 oracle 是否注入不可实现的信息。https://arxiv.org/abs/2610.19611
- **Visual Tokens on Demand**（peripheral）— query-conditioned 跨图 token budgeting；须证实压缩后仍保持关系/计数/时序证据，而非只保留终端准确率。https://arxiv.org/abs/2610.18858

## Deep-read Candidates

### 1. DeltaStreamer: Towards Human-Like Agentic Streaming Video Understanding

- Campaign：Video and Streaming Reasoning；Agentic Visual Reasoning
- 问题：查询未知时怎样预写流式证据，并在查询后处理遗漏细节。
- 去包装后的真实变量：变化写入、查询后 replay 权限和 planner 的联合；不是“类人”记忆。
- 为什么值得深读：它直接检验 streaming 研究中的关键边界——任意回放能否绕过在线记忆限制。
- 证据缺口：`abstract-only`；需固定因果前缀、历史访问、帧/视觉 token/解码/延迟预算，分开测预写记忆、检索、回放与变化检测。项目页仅为作者摘要所列，本轮未验证。
- Paper / Project：https://arxiv.org/abs/2610.19849 · https://bbbbchan.github.io/DeltaStreamer/

### 2. Neos: Learning to Interleave Search and Visual Reasoning

- Campaign：Agentic Visual Reasoning；Multimodal Reasoning Post-training
- 问题：如何让已获取的视觉证据可操作地改变下一次检索和决策。
- 去包装后的真实变量：检索请求、Multimodal Evidence Interface 与 RL/SFT credit assignment 的共同适配；不是一个新的 search agent 名称。
- 为什么值得深读：它可把“视觉证据是否真正指导工具策略”变成可干预测量，而非只看答案提升。
- 证据缺口：`abstract-only`；需审计视觉 shortcut 过滤、reference trajectory 的 oracle 信息、MEI 容量、语料/调用/视觉 token 预算以及同调用数基线。
- Paper：https://arxiv.org/abs/2610.17043

### 3. Game2Real-Bench: Do Toy Games Reveal and Transfer to Real-World Visual Reasoning?

- Campaign：Agentic Visual Reasoning；Multimodal Reasoning Post-training
- 问题：玩具游戏的可验证视觉推理是否真的预测或改善真实任务的能力。
- 去包装后的真实变量：预先定义的游戏—现实推理能力映射和 one-shot 演示迁移；不是游戏 leaderboard。
- 为什么值得深读：若映射成立，它可提供成本更低、可干预的机制验证；若不成立，也能防止游戏分数被误作真实推理证据。
- 证据缺口：`abstract-only`；需检验相关性的层级聚合、任务配对独立性、语言 shortcut、提示预算、跨模型稳健性，以及摘要称感知退化的条件。代码/数据链接仅为作者摘要所列，本轮未验证。
- Paper / Code：https://arxiv.org/abs/2610.18834 · https://github.com/QingAnLiu/Game2Real-Bench
