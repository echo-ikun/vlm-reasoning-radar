## Deep-read Candidates

### 1. InteractionBench: A Real-Time Interaction Benchmark for Streaming Video Systems

- Campaign：Video and Streaming Reasoning；Agentic Visual Reasoning
- 问题：助手何时应答、何时沉默，且离线准确率能否预测这种在线行为。
- 去包装后的真实变量：带负流和 look-alike near miss 的视频时钟评测，分别计 timing、silence 与内容；不是单纯新增一个流式 QA 集。
- 为什么值得深读：它可统一审计 CASE、OneStreamer、PREM 这类系统的 accuracy–timing–silence–cost 取舍。
- 证据缺口：`abstract-only`；需核对触发标注、视频泄漏、poll interval、端到端延迟与调用成本，以及 memory/controller 的匹配消融。摘要页列有项目、代码和数据入口，但本轮未验证可用性。
- Paper：https://arxiv.org/abs/2610.05775

### 2. VideoResearchAgent: Grounded Task Synthesis and Sim-to-Real RL for Open-Web Video Research

- Campaign：Agentic Visual Reasoning；Video and Streaming Reasoning；Multimodal Reasoning Post-training
- 问题：agent 如何在开放网页发现视频、浏览时间证据并给出有视觉依据的多跳回答。
- 去包装后的真实变量：基于 timestamped visual evidence 的任务合成、保持部署交互的本地 simulator，以及对检索排序/干扰项/元数据随机化的 GRPO；三者共同改变训练分布。
- 为什么值得深读：它将“工具使用是否真的改善取证”推进到可测的 sim-to-real 检索偏移，但也最容易受文本捷径与 simulator shortcut 影响。
- 证据缺口：`abstract-only`；必须验证任务是否排除文本捷径、证据时间戳、浏览预算、真实网页偏移与逐项消融，不能把 40.48% 摘要结果当成已确认事实。
- Paper：https://arxiv.org/abs/2610.04911

### 3. Residual Visual Credit Optimization: Conserved Evidence Routing for Multimodal Reinforcement Learning

- Campaign：Multimodal Reasoning Post-training；Agentic Visual Reasoning
- 问题：outcome-only RL 怎样把信用分给实际依赖视觉证据的推理 token。
- 去包装后的真实变量：受控视觉干预产生的 token-level response，经归一化和带质量约束的路由器重新分配 sequence utility；不是修改 reward 或 rollout。
- 为什么值得深读：如果 visual intervention 可靠，它提供了把“grounded credit”变为可消融训练变量的路径，能直接补上 MeSD 等方法的 privileged evidence 审计。
- 证据缺口：`abstract-only`；需先量化干预构造与额外计算，做随机/文本干预、matched-compute RLVR 与跨视觉捷径数据对照，并检查 credit 是否真对应因果证据。
- Paper：https://arxiv.org/abs/2610.04918

## Watchlist

- **ReMem** — 历史压缩加查询恢复的 streaming memory；必须匹配 memory 容量、严格前缀、读写 token 和检索次数。https://arxiv.org/abs/2610.05940
- **Self-Grounded Attention** — reasoning 文本决定 attention supervision 区域；attention 对齐不是 reasoning faithfulness，需做遮挡与文本长度控制。https://arxiv.org/abs/2610.05023
- **DiVeR** — 用候选动作表征离散度选择 verifier 的训练关键状态；需匹配 candidate 数与机器人试验预算。https://arxiv.org/abs/2610.04933
- **QASLR** — 固定 latent 跨 clip 聚合提升长视频 embedding；它是 retrieval 表征改进，不能直接等同在线推理提升。https://arxiv.org/abs/2610.04864
- **How (and How Not) to Use Data Augmentation in VLA Post-Training** — critic-only augmentation 是清晰控制变量；仍需跨 VLA、OOD protocol 与 reward setting 复核。https://arxiv.org/abs/2610.05994
