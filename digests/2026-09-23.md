## Deep-read Candidates

### 1. Seeing is not Enough: Vision-Language Models Perceive Evidence but Fail to Act

- Campaign：Agentic Visual Reasoning；Multimodal Reasoning Post-training
- 问题：VLM 已正确识别候选视觉证据时，为何最终决策仍越过证据允许的过程状态而过度承诺。
- 去包装后的真实变量：九类过程图像的 perception/process error 分解，以及 generic SRT 与已知阶段边界的 boundary-aligned SRT 对照。
- 为什么值得深读：摘要承认通用 SRT 不稳定优于强 CoT，真正大增益依赖相关阶段边界；这把研究窗口清楚地推向“如何发现决策边界”，而非继续包装提示模板。
- 证据缺口：`abstract-only`；需检查模糊性标注、boundary oracle 是否泄漏答案、matched-token 对照、模型转移失败，以及降低 over-commitment 是否靠拒答换取。
- Paper：https://arxiv.org/abs/2609.22588

### 2. Visual Graph Reasoning via Knowledge Compilation

- Campaign：Multimodal Reasoning Post-training
- 问题：视觉图推理失败究竟来自拓扑恢复错误，还是在正确图状态上执行了错误操作。
- 去包装后的真实变量：显式 representation compiler、executable operation compiler、四层 RL reward，以及另行加入的 archive retrieval/code reuse。
- 为什么值得深读：它与 DRT 形成互补：一个压缩 observation/deduction trace，一个强制恢复可执行图状态；可直接检验结构化中间状态何时真正带来 grounded reasoning。
- 证据缺口：`abstract-only`；需拆开两类 compiler、分层奖励和检索复用，核对图恢复准确率、工具预算、模板泄漏与三个现实域的真实性。
- Paper：https://arxiv.org/abs/2609.22327

### 3. PREM: Prefix-Steered Recurrent Memory for Long-Video Understanding

- Campaign：Video and Streaming Reasoning
- 问题：长视频如何在固定视觉预算下保留瞬时证据，并把一次写入摊销到多次查询。
- 去包装后的真实变量：recurrent writer 压入固定 256 KiB 状态，query-conditioned readout 再以 K/V modulation 改写非视觉 prompt prefix。
- 为什么值得深读：它明确分离 ingestion 与 answering，且不靠追加 memory token；若 matched total compute 下成立，是 streaming memory 的可审计系统接口。
- 证据缺口：`abstract-only`；当前只报告 offline 与 end-of-stream streaming，不等于任意时刻在线回答。需核对写/读延迟、frame sampling、因果性、固定状态容量和多查询摊销条件。
- Paper：https://arxiv.org/abs/2609.23601

## Watchlist

- **INTCORT** — 以几何图像变换和 query reversal 构造等价视图，再按 relation-token confidence 路由；摘要称平均提升 10.01%，但必须用 matched-call 多数投票/自一致性排除纯 test-time compute，并检验 selector calibration。https://arxiv.org/abs/2609.24813
- **H-VLA** — 把 key-action 子目标与稠密 motion planning 分层，并同时引入 camera-centric action space；位置 OOD 提升 47 点很强，但需先分离层级 reasoning 与动作表示对齐。https://arxiv.org/abs/2609.22895
- **GameReplica** — 125 个黑盒游戏复现任务要求 agent 用截图与动作主动试验后归纳规则；视觉外观分显著高于规则/实现一致性，但 coding ability、探索预算和训练污染是主要混淆。https://arxiv.org/abs/2609.22308
- **Validating, Not Sampling** — peripheral evaluation；以 margin-aware 验证覆盖连续亮度/旋转区域，摘要称 VLA 在正负 1 度旋转下即可改变动作；需区分数值 action flip 与真实闭环失败，并审计 soundness 假设。https://arxiv.org/abs/2609.22293
