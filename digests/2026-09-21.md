## Deep-read Candidates

### 1. When Should a Failing Robot Ask? Initiating Corrective Human-Robot Dialogue from Audited Sensor Evidence

- Campaign：Agentic Visual Reasoning；Video and Streaming Reasoning
- 问题：机器人失败后应自行诊断、查询另一传感器还是询问人类，决策能否真正随证据可辨识性、实测准确率和询问成本变化。
- 去包装后的真实变量：已知真因的故障注入、逐传感器可辨识性审计、选项顺序控制，以及 act / consult-sensor / ask-human 三动作成本决策。
- 为什么值得深读：摘要给出反直觉诊断——VLM 拒答随选项顺序崩塌、自报置信度不含正确性信息、ask rate 忽略四倍成本；这直接挑战常用 uncertainty routing。
- 证据缺口：`abstract-only`；需核对样本量、故障分布、泄漏检查、prompt sweep 配对、力数据文本化公平性，以及最优策略是否闭环实测。
- Paper：https://arxiv.org/abs/2609.21942

### 2. SeeQ: Training Generalist Value Functions for Long-Horizon Robotic Manipulation

- Campaign：Multimodal Reasoning Post-training；Agentic Visual Reasoning
- 问题：稀疏任务奖励下，通用 value function 如何缩短 credit assignment，并在测试时无需外部阶段模块即可排序候选动作。
- 去包装后的真实变量：用离线子任务边界把 task-level Q 拆成 current-subtask Q；测试时先生成当前子任务文本，再估值并做 best-of-N steering。
- 为什么值得深读：它可与 StageGuard 的阶段切换、CommitFlow 的阶段承诺和 TraceFlow 的轨迹检索放在同一控制面，测试“阶段状态”是否真是有效价值抽象。
- 证据缺口：`abstract-only`；需核对子任务注释成本与泄漏、TD 数据覆盖、语言阶段预测准确率、候选数和 matched inference budget。
- Paper：https://arxiv.org/abs/2609.22085

### 3. PRIME: Perception Feedback with Situational Memory Embeddings in VLA Models

- Campaign：Video and Streaming Reasoning；Agentic Visual Reasoning
- 问题：自动驾驶 VLA 的当前感知能否由过去推理、目标与预测行为反向调节，从而优先读取与当前意图相关的证据。
- 去包装后的真实变量：把过去 perception、reasoning、navigation goal 和 predicted behavior 在 L 步窗口中聚合成 memory，再条件化当前 perceptual queries。
- 为什么值得深读：它把 temporal memory 与 reasoning-to-perception feedback 合并成可插拔通路，并在闭环 Bench2Drive 上报告增益。
- 证据缺口：`abstract-only`；需拆开反馈、时间递归和额外容量，检查错误记忆累积、FLOPs/KV/时延、训练数据公平性与安全分项。
- Paper：https://arxiv.org/abs/2609.22040

## Watchlist

- **CommitFlow** — 用阶段 physical commitment monitor 阻止过早推进，再做局部 flow correction；摘要称 RoboTwin 2.0 平均成功率 75.9%，但未给监控误判、额外调用或 verifier/correction 独立贡献。https://arxiv.org/abs/2609.21908
- **MAAP** — 多机械臂腕部相机同时承担执行和视角覆盖，并以角色监督联合生成动作；需证明 79.2% 仿真结果不是更多静态相机/token，而是真正主动证据获取。https://arxiv.org/abs/2609.21929
- **CARF** — 用成功示范及扰动训练 progress scorer，对失败轨迹中的推进片段 attraction、失败关键片段 repulsion；摘要没有绝对结果，需审计负片段误标与合成扰动偏差。https://arxiv.org/abs/2609.21982
- **VLA-Precision v3** — 9 月 18 日重要修订把 intervention、回报传播、偏好排序和 streaming 系统共同用于真实化学操作；需先确认 v3 改动并分离算法与 10.9× 系统增益。https://arxiv.org/abs/2609.04355
- **DiaVLo** — peripheral evaluation；用行为 specification 与概念因果估计诊断 VLM 错配，需排除 VLM 生成评测规范的循环偏差，并验证干预而非相关性。https://arxiv.org/abs/2609.22008
