## Deep-read Candidates

### 1. Dissecting Advantage-Guided Post-Training for Vision-Language-Action Policies

- Campaign：Multimodal Reasoning Post-training
- 问题：advantage 构造、校准和加权在 VLA 后训练中各自带来什么，而非仅看端到端 recipe。
- 去包装后的真实变量：temporal-difference advantage、group-wise calibration、continuous weighting，以及用离线诊断筛选组合的流程。
- 为什么值得深读：它直接提供拆解 RL/VLA 增益所需的控制框架；若 offline-to-robot 选择有效，可显著降低研究配方搜索成本。
- 证据缺口：`abstract-only`；需核对任务/试验数、robot-time、critic 数据来源、离线选择偏差和跨视觉/embodiment 泛化。
- Paper：https://arxiv.org/abs/2609.28161

### 2. Watch, Recall, Act: Always-On Robots in Concurrent Embodied Streams

- Campaign：Agentic Visual Reasoning；Video and Streaming Reasoning
- 问题：无重置的持续机器人如何同时处理新观察、远期行动历史、失效/更新的指令与双臂并发。
- 去包装后的真实变量：三个异步 context provider（观察、具身状态、自身 action history）以及从遥操作分阶段产生的训练数据。
- 为什么值得深读：它把 streaming 设定推进到“行动会改变后续证据”的 agent-causal 情形，可和 PREM 的视频 memory、MemBodied 的固定 episode memory 形成受控对照。
- 证据缺口：`abstract-only`；需审计未来信息、模块/数据逐项消融、matched FLOPs/context、指令切换和双臂冲突。
- Paper：https://arxiv.org/abs/2609.28429

### 3. MemBodied: Recurrent Associative Memory for Vision-Language-Action Models

- Campaign：Agentic Visual Reasoning；Video and Streaming Reasoning
- 问题：依赖早期观测的操作任务如何避免历史 context 随 episode 增长。
- 去包装后的真实变量：固定大小的 associative interaction state 加 initial-scene anchor，而不是直接保留过往图像。
- 为什么值得深读：它给出比 ARMS 更小的 memory-interface 基线，适合先验证“什么应持久化”而不是把增益混入完整流式系统。
- 证据缺口：`abstract-only`；需检查 memory 大小、写读频率、基准输入预算、初始锚点泄漏和不需要记忆时的退化。
- Paper：https://arxiv.org/abs/2609.28256

## Watchlist

- **EmbodiedMemory-Bench** — 将具身 memory 拆为视觉细节、动态状态、交互结果与经验泛化四类能力；先审计历史证据是否必要，以及是否存在 oracle state/text 泄漏。https://arxiv.org/abs/2609.28236
- **TANDEM** — 用 task-motion planner 选择何时向人索取 demonstration；数据效率强信号，但强 planner 先验、轨迹对齐和数据分布同时变化，不能直接归因于 VLA 后训练。https://arxiv.org/abs/2609.28314
- **MultiVENT-Raw** — 近 12 万条 raw video 的检索再报告基准；应先核对时间/来源 split、检索与 report factuality 是否分开评测，不能将它直接称作 streaming reasoning。https://arxiv.org/abs/2609.28437
